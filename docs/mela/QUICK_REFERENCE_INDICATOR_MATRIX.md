## QUALITY ASSURANCE CHECKLIST BY INDICATOR

### 7 Flagged Indicators Requiring Special Attention

**INT-06: Funding facilitated (attribution clarity)**
- [ ] Document funding source (HENT vs. external)
- [ ] Track timing of attribution
- [ ] Separate facilitated from directly awarded

**INT-14: Non-financial resources value (valuation methodology)**
- [ ] Use standardized valuation method
- [ ] Document assumption basis
- [ ] Get external validation for large values

**IMM-11: MVP iterations (definition consistency)**
- [ ] Define what counts as "iteration"
- [ ] Document changes per iteration
- [ ] Use consistent tracking across cohorts

**INT-O-07: Product-market fit (assessment framework)**
- [ ] Use standardized PMF assessment tool
- [ ] Train assessors for consistency
- [ ] Document evidence supporting PMF claim

**INT-O-14: Gender gap (sample size)**
- [ ] Track cohort composition by gender
- [ ] Note when samples are <30
- [ ] Include confidence intervals in reporting

**LTO-02: Lives impacted (attribution methodology)**
- [ ] Use rigorous impact assessment framework
- [ ] Get external validation
- [ ] Document assumptions and limitations

**LTO-10: Economic value (calculation methodology)**
- [ ] Define calculation method clearly
- [ ] Get CFO approval for approach
- [ ] Annual independent validation
